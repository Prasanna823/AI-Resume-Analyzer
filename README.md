# AI Resume Analyzer

An AI-powered resume analysis web application built using Flask, Python, HTML, CSS and JavaScript.

## Features

- User Signup
- User Login
- SQLite Database
- Resume PDF Upload
- Drag and Drop Upload
- ATS Score
- Skill Detection
- Job Role Matching
- Missing Skill Detection
- Resume Improvement Suggestions
- Analysis History
- Responsive UI
- Modern Dashboard
- Animated Results

## Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- PyPDF2
- Font Awesome
